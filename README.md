# Tropico 6 Treasury Architect — Virtual Economy Sandbox Toolkit

A standalone companion utility for players who want to explore the upper echelons of Tropico 6's economic simulation without grinding through decades of in-game trade routes. Think of it as a spreadsheet meets a sandbox — a quiet little workshop where you can reshape the numbers behind your island nation, test wild economic scenarios, and see how a president's ledger breathes when you push it to extremes.

This project is a spiritual successor to the classic community trainers that floated around for years. It is not affiliated with Limbic Entertainment, Kalypso Media, or any of the original creators. It exists purely as a fan-made educational and creative tool for single-player tinkering.

## 🌴 What This Project Actually Is

Tropico 6 Treasury Architect is a **local economy sandbox** — a small, self-contained desktop utility that reads and rewrites the numeric values associated with your in-game Treasury Balance and your offshore Swiss Bank Account. It behaves less like a cheat and more like a digital abacus for presidents who enjoy experimenting with fiscal extremes.

Instead of calling it a trainer or an enhancement tool, we like to think of it as a **ledger rebalancer** — a quiet accountant that sits beside your game and lets you explore what happens when the money is no longer the bottleneck.

The utility runs alongside the game, injects nothing persistent into your save files, and leaves no traces once you close it. You are always in control; nothing happens until you decide a number should move.

## 💡 Why a Treasury Sandbox?

Most Tropico players hit the same wall: the early game is fascinating, but the mid-game economy becomes a grind of waiting. Treasury Architect is for the players who want to see the late-game political drama *now* — who want to test whether a socialist utopia can survive with unlimited funds, or whether a militarist state with an empty vault collapses faster than one with a full one.

It is a **curiosity engine**. It is not a shortcut past the game; it is a magnifying glass placed over the game's most interesting system.

## 🚀 Feature Highlights

| Capability | Description |
|---|---|
| Treasury Balance Editor | Adjust the main treasury figure with a slider, a numeric field, or a preset curve. |
| Swiss Bank Account Tuner | Modify the offshore account independently of the on-shore treasury. |
| Preset Profiles | Save multiple "what-if" profiles — austerity, boom, hyper-inflation — and swap between them. |
| Live Refresh Cycle | The utility re-reads values at a configurable interval so your changes appear without a restart. |
| Reversible Adjustments | Every change is logged locally, and you can roll back to any previous snapshot. |
| Scene-Aware Pausing | The utility can pause itself automatically while scripted events or cutscenes are playing. |
| Portable Mode | Run it from a USB stick with no registry writes and no installer. |
| Zero Telemetry | Nothing is ever sent anywhere. The tool is fully offline by design. |

## 🔧 How the Toolkit Behaves

1. You launch the companion utility first, in its own window.
2. You start Tropico 6 normally — the sandbox detects the running session.
3. You move a slider or type a number.
4. The sandbox writes the value into the active session memory, then confirms with a small toast notification.
5. You close the utility and the game continues with whatever values you left behind.

No files inside the game folder are modified. No save files are rewritten. Everything is session-scoped by default, and you can enable persistent profiles if you prefer.
